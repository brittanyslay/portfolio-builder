  1. → Click Domain management in the left menu
  2. → Click Add a domain, then Add a domain you already own
  3. → Type {{DOMAIN}} — no www, no https://
  4. → Click Verify, then Add domain

Keep this tab open — you'll copy these into {{REGISTRAR_NAME}} next:

Point {{DOMAIN}} at your new site

Tells {{DOMAIN}}, which you already own, where to send visitors.

1

Open the domain's DNS settings

  1. → Sign in at namecheap.com
  2. → Click Domain List, find {{DOMAIN}}, click Manage
  3. → Click the tab labeled Advanced DNS
2

Add the two records from {{HOST_NAME}}

  1. → Find Host Records, click Add New Record
  2. → Record 1: Type A Record, Host @, Value {{DNS_A_VALUE}}
  3. → Record 2: Type CNAME Record, Host www, Value the .{{HOST_APP_DOMAIN}} address from {{HOST_NAME}}
  4. → Click the green checkmark to save each one
Already a record at Host @ or www? Delete only that one. Never touch MX or TXT — those run email.

3

Wait, then check

  1. → Wait 30 minutes to a few hours (rarely, up to a full day)
  2. → Visit {{DOMAIN}} — it should load your site
  3. → Back in {{HOST_NAME}}'s Domain management, {{DOMAIN}} shows a green checkmark when connected
Not working after hours? Check for a typo — compare values character-by-character.
